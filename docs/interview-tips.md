# Interview Tips

Reference material for candidates. Share when relevant during a session.

1. **Start with the simplest version that works** - fix syntax first
2. **Test frequently** - after each step, verify it works
3. **Ask clarifying questions** - "Should I handle concurrent access?"
4. **Explain your thought process** - "I'm using a heap because..."
5. **Handle edge cases** - don't assume perfect inputs
6. **Use appropriate data structures** - heap for min/max, dict for lookup
7. **Write clean code** - no duplication, clear names, proper separation
8. **Document as you go** - docstrings and comments
9. **Time management** - core functionality first, optimizations later
10. **Be ready to extend** - anticipate follow-up questions
