# General Pitfalls to Avoid

Reference material for post-implementation review or when a candidate repeats a pattern.

1. **Leaving placeholders** - implement all requirements
2. **Copy-paste code** - extract to helper methods
3. **Ignoring edge cases** - validate all inputs
4. **Wrong data structures** - match structure to use case
5. **Incomplete initialization** - populate all data structures
6. **Poor naming** - use clear, consistent names
7. **Missing return statements** - handle success and failure paths
8. **No testing** - always verify your code works
